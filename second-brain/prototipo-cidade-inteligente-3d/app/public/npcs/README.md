# Personagens (GLB)

Pasta pública servida na raiz do build: um arquivo aqui vira `/<nome>.glb` no
endereço publicado.

Coloque aqui o `.glb` dos personagens e seus arquivos de apoio (textura,
`.bin`) quando o pack estiver disponível. `npcs.js` é quem consome esses
arquivos.

Origem pretendida: *Casual Character Pack Lite* (IzIBrizi, CGTrader) —
royalty-free para uso no projeto, com download sujeito a conta no site.
