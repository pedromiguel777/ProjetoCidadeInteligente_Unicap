# Dados Abertos

> Publicar não é abrir. Abrir é publicar com licença clara, formato utilizável, dicionário e atualização previsível.

## Critérios de abertura real

| Critério | Pergunta de teste |
| --- | --- |
| Legal | Há licença explícita que permite reuso comercial? |
| Técnico | Formato legível por máquina (CSV/JSON/GeoJSON), não PDF? |
| Semântico | Existe dicionário de dados? |
| Temporal | Há compromisso de atualização e histórico? |
| Acessível | URL estável, sem captcha, sem login? |

## Por que importa para o projeto

Dados abertos são o caminho mais barato para [[Arquitetura de Dados Urbanos]] e o insumo natural de um piloto sem compra de sensores. Também são a base de qualquer [[Dashboard de Indicadores]] público.

## Limites

- Aberto não é o mesmo que útil: sem [[Letramento de Dados]] o dado não circula.
- Aberto não resolve dado que nunca foi coletado — ver [[Sensores e Redes de Sensores]].
- Dado agregado pode reidentificar pessoas em áreas pequenas — ver [[Privacidade e LGPD]].
