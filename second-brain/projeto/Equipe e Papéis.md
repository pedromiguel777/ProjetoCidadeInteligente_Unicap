# Equipe e Papéis

> Papel é responsabilidade, não cargo. Cada papel tem uma nota dona neste cofre.

## Papéis mínimos

| Papel | Responsabilidade | Notas donas |
| --- | --- | --- |
| Coordenação | escopo, prazo, relação institucional | [[Escopo do Projeto]], [[Cronograma e Entregas]] |
| Pesquisa | desenho, instrumentos, análise | [[Metodologia de Pesquisa]] |
| Dados | pipeline, qualidade, catálogo | [[Arquitetura de Dados Urbanos]] |
| Campo/hardware | instalação e manutenção de sensores | [[Sensores e Redes de Sensores]] |
| Interface | painel e comunicação pública | [[Dashboard de Indicadores]] |
| Ética/legal | LGPD, parecer, termo de uso | [[Privacidade e LGPD]] |
| Articulação comunitária | relação com moradores e conselhos | [[Participação Cidadã]] |

## Regras de trabalho

- Uma pessoa pode acumular papéis, mas as **notas donas** precisam ter nome.
- Toda reunião gera pelo menos uma alteração em alguma nota ou uma entrada em [[Caixa de Entrada]].
- Quem entra no projeto lê [[00 - Início]] antes de qualquer coisa.
