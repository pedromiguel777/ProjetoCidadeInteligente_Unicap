# O que é uma Cidade Inteligente

> Cidade inteligente é a que usa dados e tecnologia para **decidir melhor**, e não a que tem mais sensores.

## Definição de trabalho

Uma cidade inteligente articula três coisas ao mesmo tempo: infraestrutura de coleta ([[Internet das Coisas Urbana]]), capacidade institucional de transformar dado em decisão ([[Governança de Dados]]) e um projeto político explícito de reduzir desigualdade ([[Inclusão Digital]]). Faltando qualquer uma das três, sobra marketing.

## O que **não** é

- Não é um pacote de fornecedor ([[Plataformas de Cidades Inteligentes]]).
- Não é sala de controle com telões.
- Não é sensor por sensor sem [[Arquitetura de Dados Urbanos]] por trás.
- Não é vigilância com outro nome ([[Vigilância e Segurança Pública]]).

## Teste de três perguntas

1. Que decisão concreta muda por causa desse dado?
2. Quem responde quando a decisão é errada?
3. Quem ficou de fora e como isso foi medido?

Se as três não têm resposta escrita, o projeto ainda é uma promessa.
