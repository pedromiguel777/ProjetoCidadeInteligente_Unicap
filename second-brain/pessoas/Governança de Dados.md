# Governança de Dados

> Sem dono, política e auditoria, dado urbano é passivo, não ativo.

## Os quatro elementos

1. **Propriedade** — quem responde por cada conjunto de dados (papel, não pessoa física).
2. **Política** — o que pode ser coletado, por quanto tempo, com quem compartilhado.
3. **Qualidade** — SLA de atualização e critério de aceitação do dado.
4. **Auditoria** — trilha de quem acessou e quem alterou. Sem isso não há prestação de contas.

## Mínimo viável para o projeto

- Catálogo de dados com dono declarado — deriva de [[Arquitetura de Dados Urbanos]].
- Termo de uso e base legal por conjunto — ver [[Privacidade e LGPD]].
- Comitê simples (academia + município) decidindo exceções — ver [[Hélice Tríplice]].
- Registro público de decisões baseadas em dado — ver [[Dashboard de Indicadores]].

## Sintomas de ausência

- Duas secretarias com números diferentes para o mesmo indicador.
- Ninguém sabe de onde veio a planilha que embasa o decreto.
- Pedido de dado aberto respondido com PDF escaneado.
